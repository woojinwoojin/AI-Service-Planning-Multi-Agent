| 경로 | 병합 | 결과 | 누가 썼나 |

6. **쪽수는 1,700자/쪽 어림이다.** 정확한 쪽수는 Word 렌더링에서만 확정된다.
7. **Artifact Contract 는 `ARTIFACT_READ_MODE=legacy` 로 배포된다.** 그래서
   *"모든 Agent 가 Artifact Contract 만을 통해 통신합니다"* 는 **과장이다.**
   정확한 표현: *"Artifact Contract 로 산출물의 소유자·근거·의존성을 관리하고, 기존 State 와의
   호환성을 검증했습니다"* — 이중 기록(dual write)과 3개 읽기 모드·parity 검증까지가 구현 범위이고,
   실제 읽기 경로 전환은 하지 않은 상태로 동결했다(전환 자체가 회귀 위험이라 후속으로 남겼다).
8. **"자율 multi-agent"라고 말하지 않는다.** 그래프가 고정이다(위 한계 표 참고).

## 배포

| 항목 | 값 |
|---|---|
| 서비스 | Cloud Run `ai-planning-agent` · `asia-northeast3` |
| URL | https://ai-planning-agent-icksipw3jq-du.a.run.app |
| 구성 | `--max-instances=1 --min-instances=0 --concurrency=8 --cpu=1 --memory=1Gi --timeout=900` |
| 모드 | 실 LLM(`USE_DUMMY=0`) · `ENABLE_DEMO_TOOLS=0` · **`ENABLE_SERVER_SAVE=0`** · `ARTIFACT_READ_MODE=legacy` |
| 공개 상한 | 실행: IP당 5회/시간 · 전역 100회/일 · 전역 **$2.0/일** / 자동완성: IP당 20회/시간(별도 버킷) |
| CD | main 머지 시 **자동 트리거** + 실서비스 반영 직전 `production` **승인 게이트** |

**배포 경로 두 개의 설정을 일치시켰다.** `scripts/deploy_cloudrun.sh` 와 `.github/workflows/
deploy-cloudrun.yml` 이 같은 옵션·환경변수를 쓴다. 어긋나면 어느 경로로 배포했는지에 따라
서비스 설정이 달라지고, 공개 상한이 '단일 프로세스·단일 인스턴스' 전제 위에 서 있으므로
그 차이가 곧 방어 강도의 차이가 된다(외부 리뷰 P1).

**확인 방법**: `/health` 의 `dummy_mode` 가 `false` 여야 실 모드다. **배포 성공 ≠ 실 모드** —
2026-07-28 에 모든 단계가 success 인데 공개 URL 이 더미로 덮인 일이 실제로 있었다.

`--max-instances=1` 은 필수다. `public_guard` 의 카운터가 프로세스 메모리라 인스턴스가 늘면
상한이 인스턴스 수만큼 곱해진다(방어가 조용히 약해진다).

## 알려진 한계 (확정)

전체 목록과 근거는 [`평가기준_매핑표.md`](평가기준_매핑표.md) 의 '알려진 한계'·'미구현 — 후속 범위'
절에 있다. 발표에서 반드시 말할 것만 여기 요약한다.

| 한계 | 요지 |
|---|---|
| 자율 계획 수립 없음 | 그래프가 고정이다. **"자율 multi-agent"라고 말하지 않는다.** 동적 위임은 `research_gap`(근거 공백에만, 상한 2)까지 |
| 사실검증 범위 | 검색 요약 기준. URL 원문 미검증(Tier 3 는 후속) |
| 항목별 근거 연결 미구현 | 코드가 "이게 TAM 근거겠지"를 추론해 부록을 만들면 그것도 허위다 |
| 문서 분량 | KOSENA 권장 30~50쪽 vs 약 11쪽. **분량을 위한 분량은 넣지 않기로 판단**(평가표 '문서 완성도'와 어긋남) |
| 품질 게이트 판정 안정성 | 같은 문서를 반복 판정하면 `fact_support_rate` 가 0.2~0.9 로 벌어진다(verify 가 주장을 매번 새로 추출) → 게이트 판정에 운이 섞인다. **미해결** |
| 이력 비영속 | Cloud Run SQLite 는 재시작 시 사라진다. 사용자에게 산출물 다운로드를 안내하는 것으로 대응 |
| **이력에 인증이 없다** | `/projects`·`/projects/{id}` 는 인증 없이 열려 있어 **남이 입력한 내용을 볼 수 있다.** 동결 직전 인증 추가는 위험이 커서, 입력 화면에 고지하는 쪽을 택했다(비민감 정보만 입력 · 시연 후 접근 제한 · 실서비스화 단계에서 소유권 적용) |
| UI 자동 테스트 없음 | node 미설치. 화면은 사람이 확인해야 한다 |
| 완전 무인 배포 아님 | 승인 게이트를 **일부러** 남겼다(실 키 붙은 공개 서비스). `can_admins_bypass=true` |
