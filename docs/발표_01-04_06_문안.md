## 01 기획 개요 및 서론 (2p · 55초 → 밀리면 50초)

### p1 — 기획 의도 · Pain Point (25초)

**제목**: "기획서는 만들 수 있다. **검증은 못 한다.**"

| 무엇이 문제인가 | 왜 |
|---|---|
| 시장조사에 시간이 든다 | 자료를 찾고 정리하는 작업이 반복된다 |
| 기획서 형식이 흔들린다 | 방법론을 지켰는지 사람이 확인해야 한다 |
| **출처가 남지 않는다** | 결과를 나중에 검증할 수 없다 ← **이걸 중심에 뒀다** |

**하단 한 줄**: LLM 으로 기획서를 뽑는 건 이미 쉽다. 문제는 **그 내용을 믿을 근거가 남지 않는다**는 것.

#### 나레이션 (약 120자)
> "기획서를 LLM 으로 뽑는 건 이미 어렵지 않습니다. 문제는 **뽑고 나서입니다** — 이 수치가 어디서
> 왔는지, 언제 조사한 것인지가 남지 않으면 그 문서는 검증할 수 없습니다. 그래서 저는 **출처와
> 검증 과정을 산출물로 남기는 것**을 기획의 중심에 뒀습니다."

### p2 — 서비스 개요 · 대표 기능 3 (30초)

**제목**: "입력 5개 → 방법론 산출물 7종 + 근거 목록"

**파이프라인 한 줄**: 입력 → 조사·분석 → KOSENA 산출물 → 검토·수정 → 근거 검증 → DOCX/PPTX

| 대표 기능 | 한 줄 |
|---|---|
| **Multi-Agent 분석** | 조사 1 + 분석 6 + KOSENA 4 — 독립 분석은 병렬 실행 |
| **KOSENA 산출물** | 방법론 **28개 항목을 코드로 자체점검**(LLM 아님·결정적) |
| **Evidence 기반 검증** | 근거마다 `evidence_id`·조회 시점 기록 → 주장별 판정 |

**하단 지표 티저 한 줄(작게)**:
> 실 LLM 7건 측정 — 전부 완주 · 실행당 평균 **$0.022 · 166초**. 상세는 05 에서.

#### 나레이션 (약 130자)
> "사용자는 다섯 항목만 입력합니다. 그러면 조사와 분석을 거쳐 **KOSENA 방법론 산출물 7종**이
> 만들어지고, 검토·수정·근거 검증을 지나 Word 와 PowerPoint 로 나옵니다. 핵심은 세 가지입니다 —
> Multi-Agent 분업, **28개 항목 자체점검**, 그리고 **근거 추적**입니다."

### ⛔ 01 에서 하지 말 것
- "기획서를 자동으로 완성합니다" → **초안**이다. 품질 게이트 0/7 과 어긋난다
- 지표 티저를 **말로 길게 설명**하기 → 05 에서 할 이야기다. 슬라이드에만 두고 한 번 짚는다

### 깎는 지점 (−5초)
p1 표의 앞 두 줄은 읽지 않고 **세 번째 줄만** 말한다.

## 02 생성형 AI 핵심기술 (2p · 70초 → 밀리면 60초)

### p1 — 모델 스펙 · Agent 역할 분담 (35초)

**제목**: "모델 하나, 역할 열하나"

| 항목 | 값 |
|---|---|
| 모델 | **`gpt-4o-mini`** (OpenAI) · Anthropic provider 도 **지원** |
| 심판 모델 | **분리 가능**(`REVIEWER_MODEL`) — ⚠️ **측정에서는 동일 모델을 썼다** |
| 그래프 노드 | **22개 선언** · 조건부 분기로 **한 실행에 20개 실행**(실측) |
| Agent 구성 | 조사 1 + 분석 6(경쟁사·고객·SWOT·PESTEL·리스크·수익모델) + KOSENA 4 |
| 실행당 LLM 호출 | **18.4회**(범위 17~19) · 토큰 **104,190**(N=7 평균) |

⚠️ **"심판 모델을 분리해 측정했다"고 말하면 틀린다.** 분리 기능은 구현돼 있고(자기 채점 편향
완화 목적), **측정 7건은 생성·심사 모두 `gpt-4o-mini`** 였다. 정확한 표현은
*"심판 모델을 분리할 수 있게 만들었고, 이번 측정은 동일 모델로 했습니다"* 다.

#### 나레이션 (약 140자)
> "모델은 `gpt-4o-mini` 하나를 씁니다. 그래프에는 노드가 22개 선언돼 있고, 조건부 분기 때문에
> 한 번 실행하면 20개가 돕니다. 실행당 LLM 호출은 **평균 18회**입니다. 심사 모델을 생성 모델과
> **분리할 수 있게** 만들어 뒀는데, 자기 채점 편향을 줄이기 위한 것이고 **이번 측정은 동일
> 모델로 했습니다.**"

### p2 — 페르소나 템플릿 설계도 (35초)

**슬라이드**: 도판 `07-persona-templates.mmd`

| 계열 | 구조 |
|---|---|
| **A형** (수집·분석) | 역할 선언 → `[작성 원칙]` → (`[근거 공백 보고]`) → `[출력 형식]` |
| **B형** (KOSENA) | `[역할]` → `[입력]` → `[요구사항]` → `[출력 형식]` → `[검증 조건]` |
| **공통 주입 블록 2개** | `UNTRUSTED_SEARCH_GUARD`(인젝션 방어) · `NO_FABRICATION_RULE`(수치 날조 금지) |

⚠️ **프롬프트 구조를 임의로 만들어 그리지 말 것.** 코드는 위 두 형식이다
(`templates.py:31-53` A형 · `122-152` B형 · `16-29` 공통 블록).

#### 나레이션 (약 145자)
> "프롬프트는 계열에 따라 두 형식을 씁니다. KOSENA 계열은 **항목 개수 자체가 평가 대상**이라
> `[검증 조건]` 을 따로 둡니다. 그리고 **모든 페르소나에 공통 블록 두 개가 합성**됩니다 —
> 검색 결과를 지시로 받지 않게 하는 인젝션 방어, 그리고 **근거에 없는 수치를 지어내지 말라는
> 규칙**입니다. 다만 프롬프트만으로는 100% 막지 못하므로 **뒤단 검증 Agent 와 2겹**으로 씁니다."

> 마지막 문장의 근거: `templates.py:22` 주석에 그대로 적혀 있다.

### ⛔ 02 에서 하지 말 것
- "심판 모델을 분리해 채점했습니다" → 측정은 동일 모델
- "프롬프트로 환각을 차단합니다" → **2겹 방어**라고 말해야 한다. 프롬프트만으로는 못 막는다
- 프롬프트 전문을 슬라이드에 붙이기 → 읽히지 않는다. **구조만** 보여준다

## 03 아키텍처 및 설계도 (3p · 85초 → 밀리면 75초)

### p1 — 데이터 파이프라인 (30초)

**슬라이드**: 도판 `02-workflow-parallel.mmd`

**반드시 말할 2개**
1. 합류 지점은 `draft` 가 아니라 **`kosena_industry`** 다. KOSENA 4노드는 합류 뒤 **순차** 실행

2. **그래프는 고정이다.** Agent 가 다음 할 일을 스스로 계획하지 않는다

#### 나레이션 (약 120자)
> "조사가 끝나면 독립적인 분석 네 개가 **동시에** 돕니다. 합류한 뒤 KOSENA 산출물 네 개는
> **순서대로** 만듭니다 — 앞 산출물을 입력으로 받아야 하기 때문이고, 대가로 LLM 호출이 네 번
> 늘어납니다. **그래프는 고정입니다** — Agent 가 다음 할 일을 스스로 계획하지는 않습니다."

### p2 — 배포 다이어그램 (30초)

**슬라이드**: 도판 `06-cicd.mmd`

| 단계 | 내용 |
|---|---|
| PR | **CI 4게이트** — `ruff + pytest` · `gitleaks` · `pip-audit` · `docker build` |
| main 머지 | **자동 트리거** |
| 실서비스 반영 직전 | **`production` 승인 게이트** |
| 배포 | Cloud Run `asia-northeast3` · `--max-instances=1` |

⚠️ **"승인 없이 자동 배포된다"와 "승인 없이는 배포 불가"는 둘 다 틀리다** — 승인 게이트가 있고,
동시에 `enforce_admins=false` 라 관리자는 우회할 수 있다.

#### 나레이션 (약 115자)
> "PR 마다 네 개 게이트가 돕니다 — 린트·테스트, 비밀값 스캔, 의존성 취약점, 이미지 빌드입니다.
> main 에 머지되면 자동으로 배포가 시작되지만, **실서비스에 반영되기 직전에 승인 게이트를 일부러
> 남겼습니다.** 실제 API 키가 붙은 공개 서비스라 완전 무인 배포는 택하지 않았습니다."

### p3 — 정적 리소스 · CDN 구성도 (25초)

**슬라이드**: 도판 `08-static-cdn.mmd`

#### 나레이션 (약 130자)
> "정적 리소스는 **CDN 을 쓰지 않았습니다.** CSS 와 JS 를 HTML 한 파일에 넣어 외부 요청이
> 0건입니다. 빌드와 CORS 설정이 필요 없고, 폐쇄망에서도 돌고, 외부 CDN 의 가용성·공급망 위험을
> 끌어들이지 않습니다. **대가는 JS 자동 테스트가 없다는 것**이고, 실서비스화 단계에서
> Cloud Storage 와 CDN 으로 분리할 계획입니다."

⚠️ **대가를 반드시 함께 말한다.** 장점만 말하면 CDN 을 몰라서 안 쓴 것으로 읽힌다.
