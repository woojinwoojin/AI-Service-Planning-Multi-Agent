### 07 실시간 솔루션 시연 (2p · 100초)

가이드 요구가 **정상 실행이 아니라 "Edge Case 및 예외상황에 대한 실시간 예외처리 및 에러 극복"**
이다. 정상 시연만 하면 요건 미달이다.

| 초 | 환경 | 동작 |
|---|---|---|
| 0–15 | **공개 Cloud Run** | 정상 실행 실시간 시작 (`/run/stream` 진행 표시) |
| 15–20 | 〃 | **"생성에 약 3분이 걸리므로 결과는 미리 실행해 둔 것으로 이어 보겠습니다"** ← 이 한 마디 필수 |
| 20–35 | 사전 결과 | KOSENA 준수 · Evidence · Verifier 판정 |
| 35–50 | 〃 | DOCX·PPTX 다운로드 후 **실제로 열어** 표·본문 렌더링 확인 |
| 50–85 | **로컬 (분리 환경)** | Agent 강제 실패 주입 → 폴백 완주 → **`degraded` 유지** → `fallback_reasons` 표시 |
| 85–100 | 슬라이드 | 다른 예외 처리 요약 (아래 표) |

🚨 **장애 주입은 공개 배포에서 하지 않는다.** 공개 URL 은 `ENABLE_DEMO_TOOLS=0` 을 유지한다 —
켜면 외부 사용자가 임의로 Agent 를 실패시킬 수 있다. 로컬(또는 접근 제한된 별도 Revision)에서
시연하고, 별도 Revision 을 만들었다면 **발표 직후 삭제·차단**한다.

**Edge Case 목록 슬라이드 (p2)**

| 예외 상황 | 처리 | 근거 |
|---|---|---|
| Agent 노드 실패 | 폴백으로 완주 + `degraded` 유지 + `fallback_reasons`(혼잡/연결/형식/처리) | `app/services/demo.py` · 라이브 시연 |
| 검색(Tavily) 완전 차단 | 근거 0건에도 **KOSENA 26/28 완주** — 출처 항목만 미충족 | 실측(`docs/동결_기록.md`) |
| LLM 이 스키마와 다른 형태 반환 | Agent `_validate()` 가 중립값으로 흡수 + 표시 계층 `displayText()` | 실제로 화면이 죽었고 고쳤다 |
| 실행 예산 상한 도달 | 이후 LLM 호출 생략하고 폴백 완주(**강제 중단 아님**) | `BUDGET_MAX_*` |
| 프롬프트 인젝션 (검색 결과에 지시문) | 검색 결과를 `<검색결과>` 구획으로 감싸고 "지시 무시" 명시 | `templates.py:16-19` · `competitor.py:94-99` |

⚠️ 0초에 시작한 실행이 Q&A 때 끝나면 보여주는 것은 **보너스**다. 외부 API 상황에 따라 늦어질 수
