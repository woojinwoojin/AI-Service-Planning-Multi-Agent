# 시각 장애인 거동 보조 웨어러블 머신

## 문제 정의 · 목표 사용자

**문제**

보행 중 장애물·신호·경로 정보를 실시간으로 알기 어려워 독립적인 이동이 제한된다

**목표 사용자**

20대 후반에서 60대 초반의 시각 장애인으로, 독립적인 이동을 원하는 사용자

## 거시환경 — Critical Uncertainties

- Political
- Economic
- Technological

## 핵심 성공요인 (KSF)

- AI 및 머신러닝 기술을 활용한 개인 맞춤형 솔루션 제공
- 사용자 친화적인 웨어러블 기기 개발
- 비용 효율적인 제품 라인업 구축
- 정부 정책 및 교육 이니셔티브와의 협력
- 지속적인 기술 혁신 및 품질 관리

## 설계 시사점

- 정부 지원 정책을 활용하여 제품 개발 및 마케팅 전략을 수립해야 합니다.
- AI 기반 기술을 통해 사용자 맞춤형 솔루션을 지속적으로 개선해야 합니다.
- 소비자 요구에 맞춘 다양한 가격대의 제품을 제공하여 시장 점유율을 확대해야 합니다.

## 서비스 컨셉

AI 기반 장애물 인식 기능을 갖춘 웨어러블 기기는 시각 장애인의 독립적인 이동을 지원하는 데 가장 효과적이며, 기술적으로도 실현 가능성이 높고 시장에서의 수요가 크기 때문에 최종 서비스 컨셉으로 선택하였다.

## Lean Canvas 핵심

| 항목 | 내용 |
|---|---|
| Problem | 1. 보행 중 장애물이나 신호를 인식하기 어려워 안전한 이동이 어렵다. 2. 기존 보조 기기가 제공하는 정보의 한계로 인해 독립적인 이동이 제한된다. 3. 사용자 친화적이지 않은 인터페이스로 인해 기기 사용이 복잡하고 불편하다. |
| Customer | 20대 후반에서 60대 초반의 시각 장애인으로, 독립적인 이동을 원하는 사용자. |
| UVP | AI 기반 웨어러블 기기로 시각 장애인의 독립적인 이동을 지원합니다. |
| Solution | 1. 실시간 장애물 인식 기능. 2. 사용자 맞춤형 음성 안내 시스템. 3. 사용자 친화적인 터치 인터페이스. |
| Revenue | 하드웨어 판매, 소프트웨어 구독 서비스, 데이터 분석 서비스, 파트너십 및 협력. |

## 가치 제안 (VPC Fit)

고객의 독립적인 이동 욕구와 제품의 실시간 인식 기능이 잘 맞아떨어짐.

## 핵심 기능

- 실시간 장애물 인식
- 사용자 맞춤형 음성 안내
- 직관적인 터치 인터페이스
- 사용자 교육 프로그램
- 데이터 분석 서비스

## MVP 범위

MVP는 실시간 장애물 인식과 사용자 맞춤형 음성 안내 기능을 포함하며, 직관적인 터치 인터페이스를 통해 사용자 경험을 향상시킵니다. 데이터 분석 서비스는 초기 단계에서 제외됩니다.

## 우선순위 (MOSCOW)

| 구분 | 기능 |
|---|---|
| Must | 실시간 장애물 인식, 사용자 맞춤형 음성 안내, 직관적인 터치 인터페이스 |
| Won't | 고급 기능 추가, 다양한 언어 지원 |
